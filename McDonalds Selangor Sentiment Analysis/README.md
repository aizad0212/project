<u><h1>📝McDonalds Selangor Sentiment Analysis</h1></u>

Conducted a text analytics and sentiment analysis project on McDonald’s customer reviews to uncover customer perceptions, common complaints, and service improvement opportunities. The target of this analysis is the McDonald's branch located in Selangor and rated below 2.5 from Google Ratings. The project involved extract data from Google Review, cleaning unstructured text data, extracting key themes, and visualizing sentiment trends to support data-driven decision-making for business performance improvement.

<h3>⚙️ Software Usage</h3>
  > Python <br>
  > Streamlit

<h3>✏️ Analysis Features</h3>
  > Text Classification <br>
  > Sentiment Analysis <br>
  > Topic Modeling <br>
