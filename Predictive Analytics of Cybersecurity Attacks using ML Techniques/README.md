<u><h1>📝Predictive Analytics of Cyber Attacks using Machine Learning</h1></u>

Developed a predictive analytics system to analyze cybersecurity attack data and forecast potential attack types using machine learning techniques. The dataset used for this project was taken from CIC-IDS2017.The project focuses on identifying patterns in historical cyber threat data, training predictive models, and generating insights to support proactive security decision-making.

<h3>⚙️ Software Usage</h3>
  > Python <br>
  > Anaconda Navigator (Jupyter) <br>
  > Pandas
  > NumPy
  > Matplotlib
  > Seaborn
  > Scikit-learn
  > SciPy
  > Joblib

<h3>✏️ ML Usage</h3>
